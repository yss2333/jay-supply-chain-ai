# docs — the portfolio site

This folder is the site. GitHub Pages serves it from `main` / `/docs`; every page is also readable here on GitHub.

| Where | What |
|---|---|
| [`work/`](work/README.md) | **The 19 write-ups.** Start here — the index lists every one with its result |
| [`how-i-work.md`](how-i-work.md) | Validation stages, baselines, the metric rules, the decision log |
| [`diagrams/`](diagrams/) | Seven interactive diagrams: the clean-room system map, how one item is decided, and one for each of five write-ups (allocation, data integrity, the review-rule overhaul, excess and aging, freight routing). Each is one self-contained HTML file |
| [`about.md`](about.md) | Career arc, tools, background |
| [`changes.md`](changes.md) | What changed on the site, and when |
| [`archive/2023/`](archive/2023/README.md) | Earlier work: Boeing case competition, stock price forecasting, research poster |
| `index.html` | The home page. Open it locally in a browser to see the site as it renders |
| [`images/`](images/) | Charts, diagram stills and the headline cards |
| `css/`, `_layouts/`, `_config.yml` | Stylesheet, page template and Jekyll settings |

The runnable system lives outside this folder, in [`../system/`](../system/README.md).
